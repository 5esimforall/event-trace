# Event Trace · 事件追踪

Event Trace 是面向 Foundry VTT V13 的只读运行时事件观察工具：自动记录关键文档变化（含改前与改后字段差异）、屏幕通知历史、静默拦截的可取消钩子以及本机脚本异常，并在需要时随时打开时间线排查或导出诊断快照。

## 安装

适用于 Foundry VTT V13（验证版本 13.351）。将发行压缩包顶层的 `event-trace/` 目录解压至 Foundry 数据目录 `Data/modules/`，重启 Foundry 后在世界的模组管理器中启用 **Event Trace · 事件追踪**。本模组无任何前置依赖，可独立运行。

## 打开时间线窗口

可以通过以下任一方式打开或前置窗口：

- 在客户端快捷键设置中为 **打开 Event Trace** 绑定快捷键；
- 在模块设置菜单点击 **打开 Event Trace**；
- 在聊天消息、角色目录或战斗追踪器的上下文右键菜单中选择对应跳转条目；
- 若同时启用了 **Sidebar Layout**，可从侧栏动作按钮一键打开。

## 主要功能

1. **四类事件时间线**：
   - **状态变更**：追踪角色、物品、效果、Token、场景、战斗、战斗参与者、聊天消息与设置变化，仅展示有意义的字段级差异，自动忽略纯技术时间戳噪点，并对超长正文、大数组与 `data:...;base64,...` 进行安全裁剪。
   - **通知**：保留屏幕信息、警告、成功、错误与进度通知；内容相同的重复通知自动合并计数，进度通知原地更新百分比。
   - **静默拦截**：当模组在 `pre*` 等可取消前置钩子中返回 `false` 阻止操作时，记录被拦截对象、钩子名与责任模组。
   - **异常**：汇聚本机 Foundry 钩子错误、脚本异常与未处理的异步拒绝，附带精简堆栈与来源归因。
2. **动作分组与时间分段**：同步嵌套触发或同用户短时间窗内连续完成的关联文档变更自动折叠为动作组；时间线按战斗轮/回合以及跨日或 5 分钟间隔分段。
3. **多维筛选与焦点**：按类别切换、聚焦当前选中 Token/角色、按归因模组或关键词检索（搜索框内按 `Esc` 清空当前检索）。
4. **导出 JSON 快照**：一键导出包含当前筛选、激活模组清单、分组与脱敏事件的 `schemaVersion: 1` 快照文件。

## 客户端设置

所有设置均为 `client` 本地配置，绝不写入世界数据库：

- **事件历史容量上限**：`200–2000` 条（默认 `500`）。
- **动作归组时间窗（毫秒）**：`0–1000` 毫秒（默认 `250`）。
- **捕获设置变更**：是否记录可见设置更新与客户端设置变化（默认开启）。
- **静默拦截提示**：窗口关闭且发生 `false` 拦截时是否弹出轻警告（默认关闭）。

## 公开 API 与联动边界

- 在 `ready` 阶段通过 `game.modules.get("event-trace").api` 暴露只读接口：`open(filter?)`、`snapshot(options?)` 与 `summary()`。
- **独立运行与低耦合协同**：未安装或未启用 `chat-lens`、`rule-lens`、`runtime-monitor` 或 `sidebar-layout` 时全部核心能力完整可用；共同启用时仅按需显示跳转入口。
- **数据与权限边界**：所有事件仅存放在当前浏览器会话内存中，刷新页面即重置；严格遵守 Foundry 原生可见性门禁，玩家视角下不会暴露隐藏 Token、秘密战斗参与者、不可见消息、暗骰数值或受限设置。
